THE PIPELINE

How the broadcast gets made

  1. 01SIMULATOR

    Generates a fictional match: true events and per-frame player positions.

  2. 02RENDERER

    Turns positions into broadcast-style video at 25 fps.

  3. 03VISION AI

    Watches the video only — detects, tracks, and derives events frame by frame.

  4. 04STATS

    Plain code computes the exact numbers: distance, speed, possession.

  5. 05AGENTS

    Explain why a moment matters, verify every number, direct which graphic airs.

  6. 06OVERLAYS

    Timed JSON: what to show, for how long, in which mode and language.

  7. 07WEB PLAYER

    This page — plays the video, draws the overlays, switches mode and language live.
